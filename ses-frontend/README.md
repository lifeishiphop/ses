# S.E.S — 학습 공간

학생과 강사가 문제 풀이, 강의실, 과제, 커뮤니티를 한곳에서 이용하는 웹 서비스입니다.

- **학습 홈**: 참여 중인 강의와 과제, 학습 현황 확인
- **문제 풀이**: 문제 검색, Java·C++ 코드 작성·실행·제출, 최근 결과 확인
- **강의실**: 수강 신청, 신청 승인·거절, 수강생 관리
- **과제**: 마감일 확인, 코드 제출, 제출 코드 검토와 점수 확인·수정
- **커뮤니티**: 게시글과 댓글로 질문·답변 공유
- **내 계정**: 회원가입·로그인, 계정 정보 확인과 비밀번호 변경

서비스의 대상 사용자와 이용 흐름은 [서비스 소개](../README.md)를 참고하세요.
