# S.E.S — Software Engineering Supporter

**코딩 문제 풀이부터 과제 제출과 채점까지, 컴퓨터소프트웨어공학과의 학습을 돕는 서비스입니다.**

코딩 과제를 ZIP 파일로 묶고 실행 결과를 캡처해 제출하는 대신, 소스 코드를 제출하고 채점 결과를 확인할 수 있습니다. S.E.S는 문제 풀이와 수업별 과제를 연결하고, 게시판을 통해 질문과 답변을 나눌 수 있도록 돕습니다.

## 누구를 위한 서비스인가요?

- **학생**은 코딩 문제를 연습하고, 강의실에 수강을 신청한 뒤 과제를 제출하고 결과를 확인합니다.
- **강사**는 강의실과 과제를 만들고, 테스트케이스를 등록해 채점 기준을 준비합니다. 수강 신청과 학생들의 제출 내역도 확인할 수 있습니다.
- **학과 구성원**은 게시판에 글과 댓글을 남기며 학습 중 생긴 질문이나 정보를 공유합니다.

## 주요 기능

### 코딩 문제 풀이

등록된 문제를 살펴보고 제목이나 내용으로 검색합니다. Java와 C++로 작성한 코드를 실행해 결과를 확인하고, 풀이를 제출해 언어별 최근 제출 내역과 정답 여부를 확인할 수 있습니다.

### 강의실과 수강 신청

강의별 공간에서 수업과 과제를 확인합니다. 학생은 수강 신청 후 승인된 강의실을 조회하고, 강사는 자신이 개설한 강의실의 수강 신청을 승인하거나 거절할 수 있습니다.

### 과제 제출과 채점

강의실별 과제와 마감일을 확인하고 코드를 제출합니다. 등록된 테스트케이스를 바탕으로 정답 여부와 컴파일 오류, 실행 오류, 시간 초과 등의 결과를 확인할 수 있습니다. 강사는 제출된 코드와 점수를 조회하고 채점 점수를 수정할 수 있습니다.

### 게시판과 댓글

게시판에서 글을 작성하고 검색하며, 댓글로 의견과 답변을 나눕니다. 작성한 글과 댓글은 수정하거나 삭제할 수 있습니다.

## 이용 흐름

**문제 연습**

1. 문제 목록이나 검색에서 풀 문제를 찾습니다.
2. 문제에서 허용한 언어로 코드를 작성하고 실행 결과를 확인합니다.
3. 풀이를 제출하고 정답 여부와 제출 내역을 확인합니다.

**수업과 과제**

1. 강사가 강의실을 개설하고 과제와 테스트케이스를 등록합니다.
2. 학생이 수강을 신청하면 강사가 신청을 승인합니다.
3. 학생이 마감 전 과제를 제출하고, 강사는 제출된 코드와 채점 점수를 확인합니다.
